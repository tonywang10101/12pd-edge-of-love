# 愛的邊緣 / Edge of Love

透過 12 位房客的七週展覽故事，認識 DSM-5-TR 十種特定人格障礙，以及另一身體病況引起的人格改變、其他特定人格障礙兩個相關案例。

主角是一位具有心理學背景、剛搬進公寓的新房客，與住戶一起參與社區展覽。

每條路線是同一段時間的獨立演繹，切換角色不是依序與所有人交往。每人 15 幕：工作分歧、三段互惠日常、兩場三人合作、案例閱讀、關係選擇與後續。角色保有拒絕、需要時間與選擇朋友的權利。

## 執行

需要 Node.js，沒有額外套件。

```sh
npm start
npm test
```

瀏覽器開啟 http://localhost:3000 。

## 內容與學習

- 12 條專屬故事主線、36 段日常、各自的告白與戀愛／友情／距離後續。兩個具體安排在後幕回應玩家的選擇；未解決的接管或衝突不自動變成成長。
- 每幕五個對話選項：三種原有的協商、保留範圍或離開方式，加一種過度示好、一種冷淡回應。E14 同樣五選，保留戀愛／友情／距離三個方向。主線與額外日常共 1,020 句，檢查去除標點後亦無全文重複；學習題保留題目與推理選項。
- 玩家關係意願、角色意願與互動品質分開。友情意願不掩蓋傷害；分數不產生同意。主線與日常選擇都會小幅影響好感度、安全感與邊界感；日常每項變化至多 2 點，不能直接製造關係意願或共同主線回憶。
- E03 線索、E08 比較解釋、E12 資料缺口、E15 新案例，共 48 題，移除延遲回顧與等待設計。每個選項有理由，保存首次與重試；不影響關係、證據或結局，也不宣稱已驗證學習成效。
- 本幕行為、本人回顧、本人同意分享的專業摘要分開標示，作者背景另列。待確認項目不混入支持線索，不需集滿準則。
- 教學 ON 隨劇情顯示線索解析與練習題，OFF 收起這些內容；兩者都顯示好感度、安全感、邊界感與選擇增減，保存相同選擇、證據與進度。右側僅提供獨立的診斷準則參照，以按鈕切換單一內容，不列角色與診斷對照，也不顯示一般準則頁。學習回顧與這一輪證據保留於各自入口，備註集中於頁尾。E08 仍推進故事並開放下一位房客；完整角色案例移至該角色 E15 結局，並非由玩家確診。
- 三個數值共同影響初識、信任、曖昧、疏離與失衡等關係定義。低邊界且反覆越界時留下倫理爭議紀錄；後幕及結局出現角色專屬的質疑，修補後仍保留紀錄。這是虛構公寓的人際後果，並非專業懲戒判定。
- 人物卡與完成頁可選幕重玩；E14 可重選。結局比較只是預覽，不改寫進度、關係意願或已獲結果。

主線卡移除進度條、已完成／下一幕文字、案例解鎖倒數與關係標籤；選項直接呈現，不再重複提醒選擇。多人片段同時顯示在場房客的立繪，主線卡也預覽下一幕的同行者。

開場、168 個主線情境與 36 個額外日常旁白改為 100～150 字，使用短句和具體動作，移除共用的長篇反思。選項後只呈現實際回應，結局也維持短篇。先前安排與尚未處理的爭議另以可展開區塊呈現，不塞回當幕旁白。每幕顯示實際地點，同場片段在不同路線使用相同地點。選項依個別場景帶出表情、光影與立繪切換；原立繪圖檔保留。

結局先呈現故事；角色全篇完成後，可展開該角色的作者案例、自我理解、準則與這一輪證據。延伸練習也收在此處，不再在正文旁顯示一般「觀察與限制」。互動解析引用當節對話、選擇與實際反應，再說明該次回覆的意義與證據界線。

人物關係圖以故事進度與互動紀錄取代不明確的成就區塊。導覽只留最上方 header，當前場景顯示在故事面板內。

## 內容檔案

- `js/data/routeStories.js`：角色場景、日常、選項、兩個安排的後續、關係對話與後日談。
- `js/data/sharedScenes.js`：三人同場對話；不同路線可能重看。
- `js/data/storyContent.js`：事件與五類結局的組裝；臨床教材來源。
- `js/data/learningContent.js`：48 個獨立問題與逐項回饋。
- `js/data/narrativeContent.js`：短篇旁白、具體反應與結局組裝、150 字上限及互動解析。
- `js/data/characters.js`：身分、視覺、準則參照及由實際場景生成的錨點。
- `js/data/dsmReference.js`：教學用準則參照，非正式中譯本。
- `js/app.js`：選擇、分支、雙方意願、學習、證據、日記與存檔。

## 存檔與驗證

版本 2.4.0，內容版本 6。本次文字修訂延用 v6 進度，不觸發重開；舊版中途選項依原位置對應新文字，不重新套用分數。沈墨、韓梟、琉璃的友情回憶依這一輪選擇呈現，游子謙的寄信後續不再回到草稿。新版自動存檔使用獨立鍵；舊版進度與日記封存，連同更早封存保留。已開放角色保留，新故事從 E01 開始，不將舊版證據、答案或關係同意帶入。原儲存鍵與手動存檔槽不因升版刪除。

`npm test` 驗證 12 人多條完整策略、五類結局、雙方意願、待確認線索、來源與日記、選擇後果、學習首次／重試、全文字數與完成角色案例、存檔遷移、重玩與全章節呈現。歷史評估保留於 `reviews/2026-11-14/v6改版驗收/`；本次字數、對話去重、120 條路徑與畫面驗證位於 `reviews/2026-11-14/短篇對話修訂/`。

本遊戲為虛構心理教育作品。專業評估與治療不由相處或戀愛代替；內容仍需精神醫療專業者、相關生命經驗讀者及真人學習成效審查。

## 背景音樂

全場景共用原創輕音樂〈公寓暮色〉，第一次點擊後以低音量淡入，換場景不重播。頂部「音樂／靜音」控制音樂與音效，記住此瀏覽器的靜音設定；切到其他分頁時暫停。音檔與重新產生方式見 `assets/audio/README.md`。
